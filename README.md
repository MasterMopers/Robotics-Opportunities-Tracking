# Robotics-Opportunities-Tracking

Tracking competitions and microgrants for robotics projects.

Two tracked classes:

- **Contests** -- things I enter and compete in (hackathons, build challenges, competition tracks).
- **Microgrants** -- money I apply for and receive to build with, no competing, no company required.

Everything below `BEGIN AUTOGEN` is regenerated by `render_readme.py` from `state.db` -- do not hand-edit it, it will be overwritten. Everything above and outside that block is hand-written and safe to edit.

This repo is **public**, so its GitHub Actions minutes are unlimited (a private repo gets 2,000 free minutes/month; this weekly ~2-minute job would be far inside that budget either way).

How it works: `.github/workflows/monitor.yml` runs `monitor.py` weekly (new items -> opens a GitHub issue) and rebuilds this README monthly. See `sources.yaml` for every tracked source and the watch calendar, and `rules.yaml` for the classification rules -- tune both without touching code.
